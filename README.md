# 🎓 Student Performance Prediction (ML Project)

## 📌 Overview
This project predicts whether a student will pass or fail based on key factors like study hours, attendance, and previous marks using Machine Learning.

---

## 🚀 Features
- Data preprocessing and cleaning
- Visualization of student data
- Machine Learning model (Logistic Regression)
- Prediction of student performance (Pass/Fail)

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 📊 Dataset
A sample dataset containing:
- Study Hours
- Attendance
- Previous Marks
- Result (Pass/Fail)

---

## 🤖 Machine Learning Model
- Logistic Regression (Classification)

---

## 📈 How It Works
1. Load dataset
2. Clean and preprocess data
3. Convert categorical data to numerical
4. Split data into training and testing sets
5. Train model using Logistic Regression
6. Predict results
7. Evaluate accuracy

---

## 📷 Sample Output
- Model predicts:
  - 1 = Pass
  - 0 = Fail
